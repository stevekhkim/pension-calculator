# 연금 수령액 계산기 — 계산 명세

기준: 2026년 세법·제도. 모든 기준값은 `src/engine/params.ts` 한 곳에 있으며 매년 1회 갱신한다.

## 1. 범위

| 항목 | v1 | 이후 |
|---|---|---|
| 개인연금 | 연금저축·IRP(세액공제형), 비과세 연금보험 | 세액공제 받지 않은 납입액 분리 |
| 국민연금 | 공단 예상연금액 입력, 가입기간·소득으로 직접 계산(4-1) | 크레딧·부양가족연금 |
| 퇴직연금 DC | 연간 적립액 직접 입력, 퇴직소득세 공식 적용 | 연봉 기반 자동 적립, 중간정산 |
| 수령 방식 | 확정기간: 수령 기간 또는 소진 나이 입력 (10년 이상, 100세까지) | 종신형 |
| 세후 | 소득세 + 지방소득세 | 건강보험료(v1은 안내 문구) |

## 2. 공통 규칙

- 시뮬레이션은 **월 단위**로 한다. 연 수익률 r의 월 수익률은 `(1+r)^(1/12) − 1`.
- 나이는 만 나이, 출생연월 기준. "N세부터"는 N번째 생일이 있는 달부터를 뜻한다.
- **명목 금액**: 그 시점에 실제로 받는 금액. **현재가치**: 명목 금액 ÷ `(1+물가상승률)^(경과 개월/12)`.
- **세금은 현재가치로 환산한 금액에 현행 세법을 적용**해 구한 세율을 명목 금액에 곱한다.
  과세표준 구간·공제액이 물가만큼 조정된다고 가정하는 것과 같다.
  (명목 금액에 현행 구간을 그대로 적용하면 먼 미래의 세금이 과대 계산된다.)

## 3. 개인연금

입력: 현재 적립금, 월 적립액, 적립액 연 증가율, 적립 종료 나이, 적립기 수익률, 수령 개시 나이(55세 이상), 수령 기간 또는 소진 나이, 수령기 수익률, 과세 유형.

1. 적립기: 매월 `잔액 = 잔액 × (1+월수익률) + 월 적립액`. 월 적립액은 12개월마다 증가율만큼 오른다.
2. 적립 종료 ~ 수령 개시: 적립 없이 적립기 수익률로 운용.
3. 수령 기간
   - 실제 개시 나이 = max(수령 개시 나이, 55세, 적립 종료 나이, 현재 나이)
   - 수령 기간을 직접 넣거나, 소진 나이를 넣으면 `소진 나이 − 실제 개시 나이`로 구한다.
   - 10년 이상, 소진 나이 100세 이하로 맞춘다.
4. 수령기: 수령 기간 동안 잔액이 정확히 0이 되도록 월 수령액을 정한다(월초 지급).
   - **구매력 유지(기본)**: 수령액이 12개월마다 물가상승률만큼 증가.
     `첫 수령액 = 잔액 ÷ Σ (1+물가)^⌊k/12⌋ ÷ (1+월수익률)^k`, k = 0 … 수령개월−1
   - **정액**: 매월 같은 명목 금액.
5. 세금
   - 세액공제형: 수령액 전액이 과세 대상(기존 적립금·납입액 모두 세액공제를 받았다고 가정).
     연금소득세(지방세 포함): 70세 미만 5.5%, 70~79세 4.4%, 80세 이상 3.3%.
   - 비과세 연금보험: 세금 0(10년 이상 유지 등 비과세 요건 충족 가정).

## 4. 국민연금

간편 입력: 공단 "내 연금 알아보기"의 예상 월 연금액(현재가치, 정상 개시연령 기준), 수령 개시 나이.

직접 계산을 고르면 4-1의 결과를 공단 조회액 대신 쓴다.

- 정상 개시연령: 1952년 이전 60세, 1953~56년생 61세, 1957~60년생 62세, 1961~64년생 63세, 1965~68년생 64세, 1969년생 이후 65세.
- 조기 수령: 1개월당 0.5% 감액(최대 60개월, 30%). 연기: 1개월당 0.6% 증액(최대 60개월, 36%).
- 현재가치 월액 = 입력값 × (1 ∓ 조정률). 명목 월액 = 현재가치 × `(1+물가)^(경과 개월/12)` (물가 연동).
- 세금(연금 외 다른 종합소득 없음, 본인 기본공제만 적용, 연금액 전액 과세 가정):
  1. 연 연금액 T에서 연금소득공제
     - 350만원 이하: 전액
     - 700만원 이하: 350만원 + 초과분의 40%
     - 1,400만원 이하: 490만원 + 초과분의 20%
     - 1,400만원 초과: 630만원 + 초과분의 10% (한도 900만원)
  2. 과세표준 = T − 연금소득공제 − 기본공제 150만원
  3. 기본세율(6~45%) 적용 후 표준세액공제 7만원 차감
  4. 지방소득세 10% 가산

## 4-1. 국민연금 직접 계산

입력: 지금까지 가입기간, 지금까지 평균 월소득, 앞으로 월평균 소득 또는 월 보험료, 납부 종료 나이. 소득은 모두 현재가치.

- 보험료로 입력하면 소득으로 환산한다: 직장가입자 본인 부담분 ÷ 4.75%, 지역가입자 ÷ 9.5% (2026년 보험료율 9.5%).
- 소득에는 기준소득월액 상한 659만원, 하한 41만원을 적용한다(2026.7~2027.6).
- 과거 가입기간은 지금까지 공백 없이 이어진 것으로 보고, 1988년 이전·18세 이전으로는 넘어가지 않게 자른다.
- 앞으로 가입기간 = 지금부터 납부 종료 나이까지.
- B값 = 과거·미래 소득을 가입월수로 가중평균한 값. A값 = 2026년 3,193,511원.
- 기본연금액(연) = Σ 가입월별 [비례상수 × (A + B)] ÷ 240
  - 비례상수: 1988~1998년 2.4 (이 기간은 B 대신 0.75B), 1999~2007년 1.8, 2008년 1.5에서 매년 0.015씩 감소(2025년 1.245), 2026년 이후 1.29
  - 20년 가입이면 비례상수 × (A + B), 이후 1년마다 5%씩 늘어나는 법정 산식 `(1 + 0.05n/12)`과 같다.
- 월 연금액 = 기본연금액 ÷ 12. 총 가입기간이 10년 미만이면 연금 없음(반환일시금).
- 결과는 올해 A값 기준이므로 현재가치로 본다. 실제로는 수급 직전 3년 A값과 재평가된 B값을 쓰며,
  임금이 물가보다 빨리 오르면 이 추정보다 조금 많아진다.
- 반영하지 않음: 출산·군복무 크레딧, 부양가족연금, 가입 공백 위치, 추후납부·반납.

## 5. 퇴직연금 DC

입력: 현재 적립금, 연간 적립액(보통 연봉의 1/12), 적립액 연 증가율(임금상승률), 입사연도, 퇴직 나이, 적립기 수익률, 수령 개시 나이(55세 이상), 수령 기간 또는 소진 나이, 수령기 수익률.

1. 적립·수령 계산은 개인연금과 같다(월 적립액 = 연간 적립액 ÷ 12).
2. **이연퇴직소득** = 퇴직 시점 적립금. 퇴직 이후 늘어난 금액은 **운용수익**.
3. 퇴직소득세 실효세율 = 퇴직소득세(현재가치 퇴직금, 근속연수) ÷ 현재가치 퇴직금
   - 근속연수 = 입사연도부터 퇴직 시점까지(1년 미만 올림)
   - 근속연수공제: 5년 이하 100만원×n / 10년 이하 500만원+200만원×(n−5) / 20년 이하 1,500만원+250만원×(n−10) / 20년 초과 4,000만원+300만원×(n−20)
   - 환산급여 = (퇴직금 − 근속연수공제) × 12 ÷ n
   - 환산급여공제: 800만원 이하 100% / 7,000만원 이하 800만원+초과분 60% / 1억원 이하 4,520만원+초과분 55% / 3억원 이하 6,170만원+초과분 45% / 3억원 초과 1억5,170만원+초과분 35%
   - 산출세액 = 기본세율(환산급여 − 환산급여공제) × n ÷ 12, 지방소득세 10% 가산
4. 수령 시 인출 순서: 이연퇴직소득 → 운용수익.
   - 이연퇴직소득 부분: 수령액 × 실효세율 × 감면 후 비율
     (수령 1~10년차 70%, 11~20년차 60%, 21년차 이후 50%)
   - 운용수익 부분: 연금소득세 5.5% / 4.4% / 3.3%(나이별)

## 6. 사적연금 1,500만원 기준

세액공제형 개인연금 수령액 + DC 운용수익 수령액의 연 합계(현재가치) P가 1,500만원을 넘으면
다음 둘 중 **세금이 적은 쪽**을 적용한다.

- 분리과세: P × 16.5%
- 종합과세: 세금(국민연금 + P) − 세금(국민연금). 4장의 세금 계산을 합산 금액에 적용한다.

이연퇴직소득과 비과세 연금보험은 이 합계에 포함하지 않는다.

## 7. 출력

- 나이별 월 수령액: 연금별 세전·세후, 명목·현재가치(해당 나이 12개월 평균)
- 구간 요약: 수령 중인 연금의 조합이 같은 나이 구간별 평균 월 수령액
- 대표값: 선택한 모든 연금이 개시된 첫 해의 월 수령액
- 연금 자산 추이: 퇴직연금·개인연금 계좌의 현재 잔액과 나이별 연말(다음 생일 직전) 잔액, 마지막 수령 시점까지.
  수령기에는 매월 지급 후 남은 금액을 수령기 수익률로 운용한다. 국민연금은 적립금 계좌가 없어 제외.

## 8. v1에서 반영하지 않는 것 (화면에 안내)

- 건강보험료(지역가입자는 국민연금 수령액의 50%가 소득으로 반영됨)
- 연금 외 소득, 부양가족 공제, 2001년 이전 국민연금 가입분 비과세
- 연금수령한도(수령 10년 미만이면 한도 초과분이 연금외수령으로 과세됨 → 수령 기간 최소 10년으로 제한)
- 세액공제 받지 않은 납입액(비과세 인출), 종신형 연금, 운용·수수료 비용
- 국민연금 소득활동 감액, 유족·분할연금
